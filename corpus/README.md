# Demonstration documents

The project owner authorized including these three supplied cricket rulebooks in this GitHub portfolio project. The PDFs are unchanged copies; their titles, scopes, relative paths and SHA-256 hashes are recorded in `manifest.json`. Original author and copyright notices remain in the documents. Inclusion does not assign ownership of third-party material or grant a new document license.

| File | Source | Pages | Scope |
|---|---|---:|---|
| pdf1.pdf | Junior Cricket Rules | 52 | September 2025; multiple age divisions and formats |
| pdf2.pdf | MCC Laws of Cricket | 79 | 2017 Code, third edition 2022 |
| pdf3.pdf | US Ismaili Games Cricket Rules | 25 | Supplied tournament rules; effective date unspecified |

The `usig_2023` source identifier does not establish a rule's effective date. These copies do not establish the current rules for another competition.

Use the repository ingestion commands to build your own lexical or Vertex index. Generated indexes, credentials, source excerpts from evaluation runs, sessions and logs remain excluded from the repository.
